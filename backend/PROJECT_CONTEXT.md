# Project Context — Loyalty Platform

## 1. Описание проекта

Платформа программ лояльности для локальных бизнесов: барбершопов, кофеен и других заведений.

Пользователь накапливает посещения в разных бизнесах и обменивает их на награды.

## 2. Технологии

- Backend: FastAPI
- ORM: SQLAlchemy 2.x, async
- Database: PostgreSQL
- Migrations: Alembic
- Frontend: React, TypeScript, Tailwind CSS

## 3. Архитектура backend

- `models/` — модели SQLAlchemy
- `schemas/` — Pydantic-схемы
- `repositories/` — запросы к БД
- `services/` — бизнес-логика
- `api/` — HTTP-эндпоинты
- `core/` — конфигурация, безопасность, общие зависимости

Уточнить структуру по фактическому состоянию проекта.

## 4. Основные сущности

- `User` — пользователь платформы
- `Business` — бизнес
- `UserBusiness` — участие пользователя в программе конкретного бизнеса; уникальная пара `user_id + business_id`; содержит баланс посещений
- `Visit` — история зарегистрированных посещений
- `Reward` — награда, принадлежащая бизнесу
- `RewardRedemption` — история обмена посещений на награды

## 5. Бизнес-правила

- Один пользователь может быть связан с одним бизнесом только один раз.
- Баланс посещений хранится в `UserBusiness`.
- Каждое посещение фиксируется в `Visit`.
- Обмен награды уменьшает баланс и создаёт `RewardRedemption`.
- Нельзя обменивать награду другого бизнеса.
- Изменение баланса и создание связанной записи должны выполняться согласованно в транзакции.
